Web 字体详解 - 学习笔记
一、常见字体格式

不同浏览器支持的字体格式不同，通常需要准备多种格式

格式 扩展名 说明 浏览器支持
TTF .ttf Windows 和 Mac 最常见字体格式 IE9+、Firefox3.5+、Chrome4+、Safari3+
OTF .otf 基于 TTF 的原始字体格式 Firefox3.5+、Chrome4+、Safari3.1+
WOFF .woff Web 字体最佳格式，TrueType/OpenType 的压缩版 IE9+、Firefox3.5+、Chrome6+、Safari3.6+
EOT .eot IE 专用字体格式 IE4+
SVG .svg 基于 SVG 渲染的字体格式 Chrome4+、Safari3.1+、iOS Mobile
二、@font-face 使用步骤

Step 1

下载字体文件（推荐 iconfont.cn）

Step 2

用 @font-face 声明字体

Step 3

给元素设置 font-family 使用

完整代码示例
/* ===== 第一步：声明字体 ===== */
@font-face {
  font-family: 'my-web-font';
  src: url('font/webfont.eot');                           /* IE9 */
  src: url('font/webfont.eot?#iefix') format('embedded-opentype'),  /* IE6-IE8 */
       url('font/webfont.woff') format('woff'),              /* Chrome、Firefox */
       url('font/webfont.ttf') format('truetype'),         /* Safari、Android */
       url('font/webfont.svg#webfont') format('svg');      /* iOS 4.1- */
}

/* ===== 第二步：定义使用样式 ===== */
.webfont {
  font-family: 'my-web-font';
  -webkit-font-smoothing: antialiased;
}
/* ===== 第三步：HTML中使用 ===== */
<p class="webfont">生命壹号，永不止步</p>
三、字体图标（Iconfont）

把图标做成字体，可以像文字一样设置大小、颜色，且具有矢量清晰、减少请求等优点

方式一：Unicode 编码引用
@font-face {
  font-family: 'iconfont';
  src: url('font/iconfont.woff') format('woff');
}
.iconfont {
  font-family: 'iconfont';
}
<!-- 编码代表图标 -->
<span class="iconfont">&#xe628;</span> 扫码付款
方式二：伪元素引用（推荐）
.icon-scan::before {
  content: "\e628";       /* 注意：这里用反斜杠 */
  font-family: 'iconfont';
  color: #e74c3c;
}
<p class="icon-scan">扫码付款</p>
常用图标库推荐
平台 网址 特点
阿里 Iconfont iconfont.cn 国内最常用，图标丰富，支持在线管理项目
Font Awesome fontawesome.com 国际知名，有免费版和 Pro 版
