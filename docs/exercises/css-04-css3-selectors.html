CSS3 选择器详解 - 学习笔记
一、属性选择器 []

匹配含义：^ 开头    $ 结尾    * 包含

E[attr] - 选中带有 attr 属性的 E 元素

a[href] → 只要有 href 属性的 a 标签都变红

a[href] {
  color: #e74c3c;
  font-weight: bold;
}

效果：

链接1 (有href) 链接2 (无href) 链接3 (有href)
E[attr="val"] - 属性值完全等于 val

a[href="./a.rmvb"] → href 完全等于 ./a.rmvb 才变红

a[href="./a.rmvb"] {
  color: #e74c3c;
}

效果：

./a.rmvb ./b.rmvb ./a.rmvb
E[attr~="val"] - 属性值包含 val（空格分隔的词）

a[class~="download"] → class 包含 download 这个词（被空格分隔开才算）

a[class~="download"] {
  color: #e74c3c;
}

效果：

download download-movie moviedownload（不匹配）
E[attr|="val"] - 等于 val 或以 val- 开头

a[class|="download"] → class 是 download 或 download-xxx

a[class|="download"] {
  color: #e74c3c;
}

效果：

download ✓ download-movie ✓ moviedownload ✗
E[attr^="val"] - 属性值以 val 开头

a[class^="download"] → class 以 download 开头

a[class^="download"] {
  color: #e74c3c;
}

效果：

download ✓ download-movie ✓ moviedownload ✗
E[attr$="val"] - 属性值以 val 结尾

a[class$="download"] → class 以 download 结尾

a[class$="download"] {
  color: #e74c3c;
}

效果：

download ✓ moviedownload ✓ download-movie ✗
E[attr*="val"] - 属性值任意位置包含 val

a[class*="download"] → class 任意位置包含 download

a[class*="download"] {
  color: #e74c3c;
}

效果：

download ✓ moviedownload ✓ download-movie ✓

三、伪元素选择器 ::

通过 CSS 模拟 HTML 标签效果，必须配合 content 属性使用

E::before - 在元素前面插入内容
span::before {
  content: "【前缀】";
  color: #e74c3c;
  margin-right: 5px;
}

效果：

这是一个 span
E::after - 在元素后面插入内容
span::after {
  content: "【后缀】";
  color: #3498db;
  margin-left: 5px;
}

效果：

这是一个 span
::before + ::after 组合 - 引号效果
.quote::before {
  content: '"';
  font-size: 24px;
  color: #e74c3c;
}
.quote::after {
  content: '"';
  font-size: 24px;
  color: #e74c3c;
}

效果：

这是一句名言
::before 实际应用 - 图标

用 ::before 在文字前面加图标，不需要修改 HTML 结构

.tip::before {
  content: "💡";
  margin-right: 5px;
}
.warn::before {
  content: "⚠️";
  margin-right: 5px;
}
.error::before {
  content: "❌";
  margin-right: 5px;
}

效果：

提示信息
警告信息
错误信息

快速导航
