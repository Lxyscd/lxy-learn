CSS3 动画详解 - 学习笔记
一、过渡 transition

实现元素不同状态间的平滑过渡（补间动画），不用管中间状态

transition 基本语法
.box {
  /* 综合写法：属性 持续时间 运动曲线 延迟 */
  transition: all 2s ease 0s;
}

/* 拆分写法 */
transition-property: all;      /* 哪些属性过渡 */
transition-duration: 1s;       /* 持续时间 */
transition-timing-function: ease;  /* linear ease ease-in ease-out */
transition-delay: 0s;          /* 延迟执行 */
transition: all - 所有属性都过渡
.trans-box {
  width: 100px;
  height: 100px;
  background: #e74c3c;
  transition: all 2s;
}
.trans-box:hover {
  width: 200px;
  background: #3498db;
  border-radius: 50%;
}

效果（鼠标悬停）：

transition: width - 只过渡宽度
.trans-width {
  width: 100px;
  transition: width 2s;  /* 只有宽度变化时有动画 */
}
.trans-width:hover {
  width: 300px;
}

效果（鼠标悬停）：

二、2D 转换 transform

实现元素的位移、旋转、缩放

transform: scale(x, y) - 缩放

大于1放大，小于1缩小；只写一个值表示等比例缩放

.scale-box {
  transition: transform 1s;
}
.scale-box:hover {
  transform: scale(1.5, 0.5);  /* 水平放大1.5倍，垂直缩小一半 */
}

效果（鼠标悬停）：

缩放
transform: translate(x, y) - 位移

参数为百分比时，相对于自身移动；正值向右/下，负值向左/上

.translate-box {
  transition: transform 1s;
}
.translate-box:hover {
  transform: translate(50px, 30px);
}

效果（鼠标悬停）：

位移
transform: rotate(deg) - 旋转

正值顺时针，负值逆时针

.rotate-box {
  transition: transform 2s;
}
.rotate-box:hover {
  transform: rotate(360deg);
}

效果（鼠标悬停）：

旋转
经典应用：绝对定位居中

利用 translate(-50%) 让绝对定位元素在父容器中水平居中（无需知道自身宽度）

.center {
  position: absolute;
  left: 50%;              /* 左边线居中 */
  transform: translateX(-50%);  /* 往左移自身宽度的一半 */
}

三、3D 转换
perspective - 透视

设置用户眼睛到平面的距离，让3D效果更明显。必须加给父元素。

.parent {
  perspective: 200px;  /* 值越小，透视效果越强 */
}
.child:hover {
  transform: rotateY(360deg);
}
rotateY - 绕 Y 轴旋转
.box:hover {
  transform: rotateY(360deg);
}

效果（鼠标悬停）：

rotateY
rotateX - 绕 X 轴旋转
.box:hover {
  transform: rotateX(360deg);

效果（鼠标悬停）：

rotateX

四、动画 @keyframes

通过设置多个节点精确控制动画，比 transition 更强大

定义动画的步骤
/* 1. 定义动画 */
@keyframes 动画名 {
  from { 初始状态 }
  to { 结束状态 }
}

/* 2. 调用动画 */
.box {
  animation: 动画名 持续时间 执行次数 是否反向 运动曲线 延迟;
  animation: move 2s infinite alternate ease-in-out 0s;
}
简单动画：移动 + 旋转
@keyframes move1 {
  from { transform: translateX(0) rotate(0deg); }
  to { transform: translateX(200px) rotate(360deg); }
}
.anim-move1 {
  animation: move1 2s infinite alternate;
}

效果（自动播放）：

多阶段动画：方形变圆形走一圈
@keyframes move2 {
  0% { transform: translate(0,0); background: red; border-radius: 0; }
  25% { transform: translate(200px,0); }
  50% { transform: translate(200px,100px); background: green; border-radius: 50%; }
  75% { transform: translate(0,100px); }
  100% { transform: translate(0,0); background: red; border-radius: 0; }
}

效果（自动播放）：

animation 属性详解
animation-name: move;           /* 动画名称 */
animation-duration: 4s;          /* 持续时间（必填） */
animation-iteration-count: infinite; /* 执行次数：1 / infinite */
animation-direction: alternate;  /* 方向：normal / alternate(往返) */
animation-delay: 1s;             /* 延迟执行 */
animation-fill-mode: forwards;   /* 结束后状态：forwards / backwards */
animation-timing-function: ease;  /* 运动曲线 */
steps() - 分步动画

steps(n) 将动画分成 n 步执行，实现不连续的动画效果（如时钟）

.hand {
  width: 3px;
  height: 80px;
  background: #333;
  transform-origin: center bottom;
  animation: tick 60s steps(60) infinite;
}

效果（时钟秒针，每格跳动）：

案例：呼吸灯效果
@keyframes pulse {
  0%, 100% { transform: scale(1); opacity: 1; }
  50% { transform: scale(1.2); opacity: 0.7; }
}
.pulse {
  animation: pulse 1.5s ease-in-out infinite;
}
