border-style 控制边框的显示样式

内容

dashed 虚线

border: 3px dashed #e74c3c;
内容

dotted 点线

border: 3px dotted #2ecc71;
内容

double 双线

border: 4px double #9b59b6;
内容

groove 凹槽

border: 6px groove #f39c12;
内容

ridge 凸槽

border: 6px ridge #1abc9c;
内容

inset 内嵌

border: 6px inset #e67e22;
内容

outset 外凸

border: 6px outset #34495e;
内容
二、圆角 border-radius

控制边框的圆角程度，值越大越圆

小圆角

内容

border-radius: 20px;
内容

正圆形

border-radius: 50%;
圆

椭圆角

三、阴影 box-shadow

box-shadow: 水平偏移 垂直偏移 模糊半径 颜色;

基础阴影

box-shadow: 2px 2px 5px rgba(0,0,0,0.3);
内容

柔和阴影

box-shadow: 0 4px 15px rgba(0,0,0,0.2);
内容

彩色阴影

box-shadow: 0 8px 30px rgba(52,152,219,0.3);
内容

内阴影

box-shadow: inset 0 0 20px rgba(0,0,0,0.1);
内容

多层阴影

box-shadow: 0 2px 5px rgba(0,0,0,0.1),
            0 8px 20px rgba(0,0,0,0.15);
内容

五、轮廓线 outline

outline 不占用盒模型空间，常用于聚焦状态或装饰效果

.box {
  outline: 3px dashed #e74c3c;     /* 轮廓样式 */
  outline-offset: 5px;             /* 轮廓与边框的距离 */
  border: 2px solid #3498db;
}
内容（outline 在 border 外面）
六、CSS 三角形

利用 border 的透明特性，设置三边透明、一边有颜色，形成三角形

/* 原理：宽高为0，三边透明，一边有色 */
.triangle-up {
  width: 0;
  height: 0;
  border-left: 30px solid transparent;
  border-right: 30px solid transparent;
  border-bottom: 50px solid #3498db;   /* 底边有色 → 朝上三角 */
}
