Sass 入门 - 学习笔记
一、Sass 是什么

Sass 是 CSS 的预处理器，让 CSS 拥有变量、嵌套、混合等功能，写完后编译成普通 CSS

Sass（源文件 .scss）

$primary: #3498db;

.btn {
  background: $primary;
  padding: 10px 20px;
  }

编译后 CSS

.btn {
  background: #3498db;
  padding: 10px 20px;
}
二、变量 $变量名

用 $ 符号定义变量，统一管理颜色、尺寸等值

/* 定义变量 */
$primary-color: #3498db;
$danger-color: #e74c3c;
$base-padding: 16px;

/* 使用变量 */
.btn-primary {
  background: $primary-color;
  padding: $base-padding;
}
.btn-danger {
  background: $danger-color;
  padding: $base-padding;
}
三、嵌套

Sass 允许选择器嵌套，模拟 HTML 的层级结构

Sass 嵌套写法

.nav {
  background: #333;

  ul {
    list-style: none;

    li {
      display: inline-block;

      a {
        color: #fff;

        &:hover {
          color: #3498db;
        }
      }
    }
  }
}

编译后 CSS

.nav { background: #333; }
.nav ul { list-style: none; }
.nav ul li { display: inline-block; }
.nav ul li a { color: #fff; }
.nav ul li a:hover { color: #3498db; }

& 表示父选择器，&:hover 编译后为 .nav ul li a:hover

四、混合 @mixin / @include

定义可复用的代码块，像函数一样传入参数

/* 定义混合 */
@mixin flex-center {
  display: flex;
  justify-content: center;
  align-items: center;
}

/* 带参数的混合 */
@mixin button($bg, $color: #fff) {
  background: $bg;
  color: $color;
  padding: 10px 20px;
  border-radius: 4px;
}

/* 使用混合 */
.modal {
  @include flex-center;
}
.btn-primary {
  @include button(#3498db);
}
.btn-danger {
  @include button(#e74c3c, #fff);
}
五、继承 @extend

让一个选择器继承另一个选择器的所有样式（编译后会合并，减少重复代码）

.message {
  padding: 10px;
  border: 1px solid #ccc;
  border-radius: 4px;
}

.success {
  @extend .message;
  border-color: green;
  color: green;
}

.error {
  @extend .message;
  border-color: red;
  color: red;
}
/* 编译结果：合并为群组选择器 */
.message, .success, .error {
  padding: 10px;
  border: 1px solid #ccc;
  border-radius: 4px;
}
六、运算

Sass 支持数学运算，让尺寸计算更方便

$base-width: 100px;

.col-2 {
  width: $base-width * 2;     /* 200px */
}
.col-3 {
  width: $base-width * 3;     /* 300px */
}
.half {
  width: 600px / 2;          /* 300px */
}
七、导入 @import

将样式拆分为多个文件，便于维护（下划线开头的文件不会被单独编译）

/* _variables.scss */
$primary: #3498db;

/* _mixins.scss */
@mixin center { display: flex; }

/* main.scss */
@import 'variables';   /* 引入 _variables.scss */
@import 'mixins';      /* 引入 _mixins.scss */

.box {
  background: $primary;
  @include center;
}
八、编译命令
# 单文件编译
sass input.scss output.css

# 监听文件变化，自动编译
sass --watch input.scss:output.css

# 监听整个文件夹
sass --watch scss/:css/

# 压缩输出（生产环境）
sass --style compressed input.scss output.css
