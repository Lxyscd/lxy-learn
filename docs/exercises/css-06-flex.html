一、声明弹性盒子 display: flex

给父容器加 display:flex，子元素自动成为弹性元素，默认从左到右水平排列

.container {
  display: flex;        /* 声明为弹性盒子（常用） */
  /* display: inline-flex;  */  /* 行内弹性盒子（少用） */
}

二、主轴方向 flex-direction

控制子元素排列方向。主轴默认水平从左到右，侧轴垂直从上到下

flex-direction: row（默认）
.container {
  display: flex;
  flex-direction: row;  /* 从左到右（默认） */
}

五、子元素属性
flex - 伸缩比例（权重）

flex: 1 表示占据剩余空间的1份；数值越大占比越大

.item1 { flex: 1; }   /* 占1份 */
.item2 { flex: 2; }   /* 占2份 */
.item3 { flex: 1; }   /* 占1份 */
/* 总份数=4，占比分别为 25% : 50% : 25% */

效果：

flex:1
flex:2
flex:1
align-self - 单独设置某个子元素的侧轴对齐
.item2 { align-self: center; }  /* 只让第2个元素居中 */

六、经典布局案例
水平垂直居中
.container {
  display: flex;
  justify-content: center;   /* 主轴居中 */
  align-items: center;       /* 侧轴居中 */
}

效果：

我在正中间
圣杯布局（头-左中右-尾）

  display: flex;

.nav { width: 100px; order: -1; }  /* 左侧固定，order调到最前 */
