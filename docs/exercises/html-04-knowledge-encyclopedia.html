0. HTML 是什么 / 页面基本结构

HTML（HyperText Markup Language，超文本标记语言）不是编程语言，而是标记语言， 用一组"标签"描述网页的内容结构。类比：网页是一栋楼，HTML 是钢筋骨架，CSS 是装修，JavaScript 是水电和电梯。

源码 
<!-- 一个最简单、最标准的 HTML5 页面骨架 -->
<!DOCTYPE html>
<!-- 上面这行：告诉浏览器"我是 HTML5 文档"。必须写在第一行，固定写法，直接背下来 -->

<html lang="zh-CN">
<!-- html：根标签，全部内容都要放在它里面。lang 属性表示网页的语言，"zh-CN"表示简体中文 -->

<head>
  <!-- head：头部区域，放"看不见"的元信息，比如标题、字符集、外链的css/js -->
  <meta charset="UTF-8">
  <!-- 字符编码设为 UTF-8，避免中文乱码，这是所有网页的必备第一行配置 -->

  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <!-- 移动端适配：让页面宽度等于设备宽度，初始缩放比例为1，做响应式网页必写 -->

  <title>我的第一个网页</title>
  <!-- 浏览器标签页上显示的标题，也是收藏夹里显示的名字 -->
</head>

<body>
  <!-- body：主体区域，放用户在页面上能"看得见"的所有内容。一个页面只能有一个 body -->
  <h1>你好，世界！</h1>
  <p>这是一个段落。</p>
</body>

</html>
逐行含义速查表
代码含义
<!DOCTYPE html>声明这是 HTML5 文档（固定写法）
<html lang="zh-CN">根标签，lang 表示语言
<head>头部区域，元信息
<meta charset="UTF-8">字符编码，防止乱码
<title>标签页标题
<body>页面主体，看得见的内容

1.3 文本级标签 vs 容器级标签

HTML 标签按能放的内容分为两大类，这个概念非常重要，贯穿整个 HTML 学习：

类型举例规则
文本级标签 p、span、a、b、i、u、em、strong 里面只能放文字、图片、表单元素。例如 p 标签里不能放 h1、div，浏览器会自动把它们拆开或忽略嵌套关系。
容器级标签 div、h1~h6、li、dt、dd、section 里面可以放置任何东西，包括别的容器级标签。
常见错误：把 h1（容器级）塞进 p（文本级）里，浏览器会自动把 p 提前闭合，不允许包裹。

4. 超链接 <a>

a 是英文 anchor（锚）的意思，是一个文本级标签。 href（hypertext reference，超文本地址）是它最核心的属性。

4.1 外部链接：链接到别的页面/网站

源码 
<a href="02页面.html">点击进入另外一个文件</a>
<a href="http://www.baidu.com" target="_blank">点我跳转百度（新标签页）</a>
效果 点我跳转百度

4.2 锚链接：跳转到页面内的某个位置

源码 
<!-- 第一步：用 id（推荐）或 name 给目标位置起个名字，作为"锚点" -->
<h2 id="top-anchor">顶部</h2>

<!-- 第二步：href 前面加 # + 锚点名，点击后跳到该位置 -->
<a href="#top-anchor">回到顶部</a>

<!-- 如果要跳转到"其他页面"里的某个锚点，写法是： -->
<a href="a.html#top-anchor">跳到a.html页面的顶部锚点</a>
<!-- 注意：# 号不能丢，丢了就变成跳到名为 top-anchor 的文件/文件夹了 -->
效果 点击跳到本章开头（本页锚点跳转示例）

4.3 邮件链接

源码 
<a href="mailto:xxx@163.com">点击进入我的邮箱</a>
<!-- 效果：点击后会弹出系统默认邮件客户端（如 Outlook），实际项目中用得不多 -->
效果 点击发邮件

4.4 超链接常用属性

属性含义
href目标 URL（hypertext reference）
title悬停提示文本，鼠标停留时出现
name（旧） / id（新）给锚点起名字
target="_self"默认值，在当前标签页打开
target="_blank"在新标签页打开
target="_parent"在父级窗口打开（配合 frame 使用）
target="_top"在最顶层窗口打开
使用规范：a 标签的语义"小于" p，正确写法是 <p><a>文字</a></p>， 而不是用 a 包裹 p。同理，a 标签里不能再放 a 或 input。

5. 图片标签 <img>

img 是单标签，能插入 jpg/jpeg、png、gif、bmp、webp 等格式，不能直接插入 psd、ai 等设计源文件格式。

5.1 图片路径：相对路径 vs 绝对路径

源码 
<!-- 相对路径：相对"当前页面"所在文件夹去找 -->
<img src="2.jpg">         <!-- 当前目录下的图片 -->
<img src="./2.jpg">       <!-- 同上，./ 可省略 -->
<img src="../2.jpg">      <!-- 上一级目录的图片 -->
<img src="images/1.jpg">  <!-- 当前目录下 images 文件夹里的图片 -->

<!-- 绝对路径写法一：本地磁盘路径（几乎不用，仅本机能访问）-->
<img src="C:\Users\xxx\Desktop\1.jpg">

<!-- 绝对路径写法二：网络地址，以 http:// 或 https:// 开头（最常用）-->
<img src="https://web.qianguyihao.com/img/logo.png">
路径面试题

已知目录结构：document/work/myweb/index.html 和 document/photo/1.png， 在 index.html 中插入 1.png 该怎么写？

答案：<img src="../../photo/1.png">（先从 myweb 回退两级到 document，再进入 photo）

5.2 img 的常用属性

源码 
<img
  src="https://via.placeholder.com/160x90/4fc08d/ffffff?text=Demo"
  alt="占位图"          <!-- 图片加载失败时显示的替代文字，也利于SEO和无障碍访问 -->
  title="鼠标悬停提示"   <!-- 鼠标悬停时出现的提示文本 -->
  width="160"           <!-- 宽度。只设置宽或高其中一个，可实现等比例缩放 -->
  height="90"            <!-- 高度 -->
>
效果
属性说明
srcsource，图片路径，必填
altalternate替代，图片无法显示时的文字
title鼠标悬停提示文本
width / height宽高，只设置一个可等比缩放
align 已废弃图片和文字的相对位置，现在用 CSS float / vertical-align 代替
border 已废弃图片边框，现在用 CSS border 代替

7. 表格标签 <table>

记住一句话：表格是由"行"组成的，行是由"列（单元格）"组成的，而不是"行和列直接组成表格"。

7.1 基本结构：table / thead / tbody / tr / th / td

源码 
<table border="1" cellpadding="8" cellspacing="0">
  <!-- caption：表格标题，要和 thead/tbody 并列写 -->
  <caption>门店销售数据</caption>

  <thead>
    <!-- thead：表头区域 -->
    <tr>
      <!-- tr：table row 一行 -->
      <th>门店名称</th>  <!-- th：表头单元格，默认加粗居中，相当于 td+b -->
      <th>城市</th>
      <th>月销售额</th>
    </tr>
  </thead>

  <tbody>
    <!-- tbody：表体区域，放真正的数据行 -->
    <tr>
      <td>小象超市·朝阳店</td>  <!-- td：table data 普通单元格 -->
      <td>北京</td>
      <td>¥12,000</td>
    </tr>
    <tr>
      <td>小象超市·浦东店</td>
      <td>上海</td>
      <td>¥15,000</td>
    </tr>
  </tbody>
</table>
<!-- 备注：写了 thead/tbody/tfoot 后，浏览器渲染顺序固定按 thead→tbody→tfoot，
     和源码书写顺序无关；数据量大时还能边获取边显示，提升体验 -->
效果
门店销售数据
门店名称城市月销售额
小象超市·朝阳店北京¥12,000
小象超市·浦东店上海¥15,000

    <td colspan="2">横向合并了2列</td>
  </tr>
  <tr>

  </tr>

16.1 sessionStorage vs localStorage

源码：常见 API

16.2 案例：记住用户名和密码（登录页常见需求）

源码 
<input type="text" class="userName">
<input type="text" class="pwd">
<input type="checkbox" class="check">记住密码
<button>登录</button>

<script>
  var userName = document.querySelector('.userName');
  var pwd = document.querySelector('.pwd');
  var chk = document.querySelector('.check');

  // 点击登录：勾选了"记住密码"就存储，否则清除
  document.querySelector('button').onclick = function () {
    if (chk.checked) {
      localStorage.setItem('userName', userName.value);
      localStorage.setItem('pwd', pwd.value);
    } else {
      localStorage.removeItem('userName');
      localStorage.removeItem('pwd');
    }
  };

  // 页面加载时：如果本地有记录，自动回填
  window.onload = function () {
    userName.value = localStorage.getItem('userName') || '';
    pwd.value = localStorage.getItem('pwd') || '';
  };
</script>

18.6 已废弃标签/属性一览（了解即可，不要在新项目中使用）

标签/属性替代方案
<font>CSS：color / font-size / font-family
