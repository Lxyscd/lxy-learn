第1章：CSS 简介与引入方式

CSS（Cascading Style Sheets，层叠样式表）控制网页的外观——颜色、大小、位置、动画等。HTML 决定"有什么内容"，CSS 决定"内容长什么样"。

CSS 三种引入方式

源码 + 注释 
/* 1. 行内样式（内联样式）：直接写在 HTML 标签的 style 属性里 */
/* 优点：优先级最高；缺点：难维护，结构和样式混在一起，不推荐 */
<p style="color: red; font-size: 16px;">红色文字</p>

/* 2. 内部样式：写在 HTML 文件 <style> 标签中 */
/* 适合：小页面、单页面 demo */
<style>
  p { color: red; }
</style>

/* 3. 外部样式表（推荐！）：独立 .css 文件，用 <link> 引入 */
/* 优点：结构和样式完全分离，多页面复用，浏览器缓存提速 */
<link rel="stylesheet" href="style.css">

/* 4. @import 导入（不推荐，性能差） */
/* 在 CSS 文件中引入另一个 CSS 文件 */
@import url("reset.css");

三种方式的优先级

当同一个元素被多种方式设置样式时，优先级从高到低为：行内样式 > 内部样式 / 外部样式（取决于在 HTML 中出现的顺序，后面的覆盖前面的）

方式写在哪优先级适用场景

内部样式HTML 的 <style> 标签中单页面、demo
外部样式独立 .css 文件中正式项目（推荐）

第3章：选择器

选择器是 CSS 的核心——决定"样式作用在哪些元素上"。

3.1 基础选择器

源码 + 注释 
/* 标签选择器：选中所有指定标签 */
p { color: #333; }
h1 { font-size: 28px; }

/* 类选择器（class）：选中 class="card" 的元素，用 . 开头 */
/* 一个元素可以有多个 class，空格分隔：class="card active" */
.card { background: white; }
.highlight { color: orange; }

/* ID 选择器：选中 id="header" 的元素，用 # 开头 */
/* ID 在页面中必须唯一，实际开发中少用 */
#header { height: 60px; }

/* 通配符选择器：选中所有元素 */
/* 常用于全局重置，但性能稍差 */
* { margin: 0; padding: 0; }

3.2 组合选择器

源码 + 注释 
/* 后代选择器：选中 .card 里面的所有 p（不管嵌套多深） */
.card p { color: #666; }

/* 子代选择器：只选中 .card 的直接子元素 p（不选孙级） */
.card > p { color: #666; }

/* 并集选择器（群组）：同时选中 h1 和 h2 */
h1, h2 { font-weight: bold; }

/* 交集选择器：选中同时有 class="card active" 的元素 */
/* 注意：两个选择器之间没有空格 */
.card.active { border-color: green; }

/* 相邻兄弟选择器：选中紧跟在 h1 后面的第一个 p */
h1 + p { margin-top: 0; }

/* 通用兄弟选择器：选中 h1 后面的所有 p（同层级） */
h1 ~ p { color: blue; }

3.3 伪类选择器

伪类用单冒号 : 表示，用于描述元素的某种"状态"。

源码 + 注释 
/* :hover —— 鼠标悬停时的样式（最常用） */
.btn:hover { background: darkgreen; }

/* :focus —— 获得焦点时（输入框聚焦） */
input:focus { border-color: blue; }

/* :active —— 鼠标按下还没松开时 */
.btn:active { transform: scale(0.95); }

/* :link —— 未访问的链接 */
a:link { color: blue; }

/* :visited —— 已访问的链接 */
a:visited { color: purple; }

/* :first-child —— 选中父元素的第一个子元素 */
li:first-child { font-weight: bold; }

/* :last-child —— 选中父元素的最后一个子元素 */
li:last-child { border-bottom: none; }

/* :nth-child(n) —— 选中第 n 个子元素 */
/* :nth-child(odd) 奇数行，:nth-child(even) 偶数行 */
li:nth-child(odd) { background: #f9f9f9; }
li:nth-child(even) { background: #fff; }

/* :nth-child(2n+1) 等价于 odd */
/* :nth-child(3n) 每第 3 个 */

/* :not() —— 否定伪类，选中不满足条件的元素 */
.menu a:not(.active) { color: #999; }

/* :checked —— 被选中的表单元素 */
input:checked + label { color: green; }

/* :disabled —— 禁用状态的表单元素 */
input:disabled { background: #eee; cursor: not-allowed; }

第4章：CSS 优先级与层叠

当多条 CSS 规则都选中同一个元素时，浏览器根据"优先级"决定最终使用哪条规则。CSS 叫"层叠样式表"——层叠就是指多条规则可以叠加在一起。

4.1 优先级排序

从高到低排列：

优先级来源示例
最高!importantcolor: red !important;
高行内样式style="color: red;"
中ID 选择器#header { }
低类/伪类/属性选择器.card { } / :hover { }
最低标签/伪元素选择器p { } / ::before { }
⚠️ 尽量不要用 !important！它会让 CSS 难以维护。推荐用 class 选择器为主，通过调整选择器组合来控制优先级。

4.2 优先级计算（权重值）

CSS 优先级用 (a, b, c, d) 四元组表示：

源码 + 注释 
/*
  优先级四元组：(a, b, c, d)

  a: 是否使用 !important（1=是, 0=否）
  b: ID 选择器的个数
  c: 类选择器、属性选择器、伪类的个数
  d: 标签选择器、伪元素的个数

  比较规则：从左到右逐位比较，左边大的胜出。
*/

/* 权重 (0, 0, 0, 1) —— 1 个标签 */
p { color: black; }

/* 权重 (0, 0, 1, 0) —— 1 个 class */
.text-red { color: red; }

/* 权重 (0, 1, 0, 0) —— 1 个 ID */
#main { color: blue; }

/* 权重 (0, 0, 1, 1) —— 1 个 class + 1 个标签 */
.card p { color: green; }

/* 权重 (0, 0, 2, 0) —— 2 个 class */
.card.active { color: orange; }

/* 权重 (1, 0, 0, 0) —— !important 最高 */
p { color: pink !important; }

/*
  特殊：行内样式优先级相当于 (0, 1, 0, 0, 0)
  只有 !important 能覆盖行内样式
*/

4.3 层叠规则

当优先级相同时，后面的规则覆盖前面的（"后来居上"）。

源码 + 注释 
/* 两条规则优先级相同（都是 1 个 class） */
.box { color: red; }    /* 先写 */
.box { color: blue; }   /* 后写，覆盖前面的 */

/* 最终文字是蓝色 */

4.4 继承

某些 CSS 属性会从父元素继承到子元素，比如文字相关的属性（color、font-size、font-family、line-height 等）。但盒模型相关的属性（width、padding、border、margin）不会继承。

源码 + 注释 
body {
  font-family: "Microsoft Yahei", sans-serif;  /* 会被子元素继承 */
  color: #333;                               /* 会被子元素继承 */
  line-height: 1.6;                           /* 会被子元素继承 */
}

.card {
  border: 1px solid #ccc;  /* 不会继承给子元素 */
  padding: 20px;          /* 不会继承给子元素 */
}

/* 可以用 inherit / initial / unset 控制继承 */
.child {
  color: inherit;   /* 显式继承父元素的 color */
  color: initial;  /* 恢复为 CSS 默认值 */
  color: unset;     /* 如果可继承则继承，否则恢复默认 */
}

/* JS 可以动态修改变量（主题切换！） */
/* document.documentElement.style.setProperty('--bg', '#1a1a2e') */
💡 CSS 变量与 SCSS 变量的区别：CSS 变量运行在浏览器端，可以被 JS 动态修改；SCSS 变量编译时固定，不能运行时修改。

第22章：媒体查询与响应式

媒体查询让 CSS 根据屏幕宽度、设备类型等条件应用不同样式。

22.1 基本语法

源码 + 注释 
/* @media 媒体类型 and (条件) { ... } */

/* 屏幕宽度 >= 768px 时应用 */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: 1fr 1fr;
  }
}

/* 屏幕宽度 >= 1024px 时应用 */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: 1fr 1fr 1fr;
  }
}

/* 屏幕宽度 <= 480px 时应用（手机端） */
@media (max-width: 480px) {
  .grid {
    grid-template-columns: 1fr;
  }
}

/* 多条件组合 */
@media (min-width: 768px) and (max-width: 1023px) {
  /* 768px ~ 1023px 之间 */
}

/* 横屏 / 竖屏 */
@media (orientation: landscape) { /* 横屏 */ }
@media (orientation: portrait)  { /* 竖屏 */ }

第23章：CSS 单位

CSS 有绝对单位和相对单位，理解它们的区别对响应式设计至关重要。

单位类型含义用途
px绝对像素固定尺寸（边框、图标）
%相对相对父元素的百分比响应式宽度
em相对相对父元素字号嵌套缩放（注意层级）
rem相对相对根元素（html）字号响应式字体（推荐）
vw相对视口宽度的 1%全屏布局
vh相对视口高度的 1%全屏布局
vmin相对视口宽高较小者的 1%适配移动端
vmax相对视口宽高较大者的 1%适配移动端
ch相对字符 "0" 的宽度等宽限制
fr相对Grid 分数单位网格列宽分配
源码 + 注释 
/* 常见用法 */
.container { width: 80%; max-width: 1200px; }  /* 居中容器 */
.title { font-size: 1.5rem; }       /* 根字号的 1.5 倍 */
.hero { height: 100vh; }            /* 满屏高度 */
.sidebar { width: 20vw; }            /* 视口宽度的 20% */

/* em 的陷阱：嵌套时层层放大 */
.parent { font-size: 20px; }
.parent .child { font-size: 1.2em; }  /* 24px */
.parent .child .grandchild { font-size: 1.2em; }  /* 28.8px！层层放大 */

/* rem 不会嵌套放大：始终相对根元素 */
html { font-size: 16px; }  /* 1rem = 16px */

23.2 calc() 计算函数

源码 + 注释 
.box {
  /* 混合不同单位进行计算 */
  width: calc(100% - 200px);   /* 全宽减去固定值 */
  height: calc(100vh - 60px);   /* 全高减去导航栏 */
  padding: calc(1rem + 2px);    /* 混合单位 */
}

/* 注意：运算符两边要有空格！ */
/* calc(100% - 200px) ✓ */
/* calc(100%-200px) ✗ */
💡 rem 适合字体大小（相对根元素，不会嵌套放大），% 适合容器宽度（相对父元素），vw/vh 适合全屏布局。

第25章：CSS 常见面试题

Q1: CSS 盒模型是什么？box-sizing 的作用？

盒模型由 content + padding + border + margin 四层组成。box-sizing: content-box（默认）的 width 只算 content，加上 padding 和 border 后实际更宽；box-sizing: border-box 的 width 包含 content + padding + border，所见即所得。实际项目全局设置 * { box-sizing: border-box; }。

Q2: CSS 选择器优先级怎么计算？

优先级四元组 (a, b, c, d)：a=是否 !important，b=ID 选择器个数，c=class/伪类/属性选择器个数，d=标签/伪元素选择器个数。从左到右逐位比较。行内样式优先级高于所有非 !important 规则。

Q3: display: none、visibility: hidden、opacity: 0 的区别？

display: none 完全隐藏，不占空间，不可交互。visibility: hidden 隐藏但占空间，不可交互。opacity: 0 完全透明，占空间，仍可交互（可被点击）。

Q4: 什么是 BFC（块级格式化上下文）？

BFC 是一个独立的渲染区域，内部元素的布局不影响外部。触发 BFC 的方式：overflow: hidden/auto/scroll、float: left/right、position: absolute/fixed、display: flex/grid/inline-block。BFC 的作用：清除浮动、防止 margin 塌陷、阻止文字环绕。

Q5: 如何实现元素水平垂直居中？

  position: absolute;

  right: 0;
  bottom: 0;
  left: 0;

}

/* 方法5：line-height = height（单行文字） */

  line-height: 40px;
  text-align: center;
}

Q7: Flex 和 Grid 有什么区别？

Flex 是一维布局，一次只能控制一个方向（行或列）的排列。Grid 是二维布局，可以同时控制行和列。Flex 适合导航栏、按钮组、卡片排列等线性布局。Grid 适合页面整体布局、表格、复杂网格。两者可以嵌套使用。

Q8: 响应式设计怎么做？

核心是使用媒体查询 @media + 相对单位 + viewport meta 标签。推荐"移动端优先"策略：先写手机端样式，再用 min-width 逐步增强到平板、桌面。Flex 和 Grid 的 fr、auto-fit 也可以实现自动响应式排列。

Q9: CSS 动画性能优化的建议？

尽量用 transform 和 opacity 做动画，避免动画 width/height/top/left（会触发重排）。对动画元素使用 will-change: transform 提示浏览器优化。避免在动画过程中频繁操作 DOM。大量元素动画时考虑用 Canvas 或 WebGL。

Q10: 什么是 CSS Reset 和 Normalize？

CSS Reset 是把所有浏览器默认样式"暴力清零"（margin: 0, padding: 0 等）。Normalize 是保留有用的默认样式，只统一浏览器之间的差异。现代项目通常用一个简化的 Reset：
