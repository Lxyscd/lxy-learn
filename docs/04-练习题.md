# HTML / CSS / JS 练习题

## HTML 练习（3 题）

### 练习 1：门店信息卡片

用 HTML 写一个门店信息卡片，要求：
- 使用语义化标签（header, main, section, footer）
- 包含：门店名称（标题）、门店地址（段落）、营业状态（加粗）
- 包含一张图片（用占位图即可）
- 底部有联系方式

**参考答案**：`exercises/html-01-store-card.html`

### 练习 2：门店录入表单

用 HTML 写一个门店信息录入表单，要求：
- 门店名称（文本输入，必填）
- 业态分类（下拉选择：超市/便利店/餐饮/其他）
- 开业日期（日期选择器）
- 是否有停车场（单选：是/否）
- 经营面积（数字输入，单位平方米）
- 备注（多行文本）
- 提交和重置按钮
- 所有输入项都要有 label 关联

**参考答案**：`exercises/html-02-store-form.html`

### 练习 3：数据表格

用 HTML 表格展示门店销售数据：
- 表头：门店名称、城市、月销售额、状态
- 至少 3 行数据
- 使用 thead 和 tbody

**参考答案**：`exercises/html-03-table.html`

## CSS 练习（3 题）

### 练习 4：卡片样式美化

给练习 1 的门店卡片添加 CSS 样式：
- 卡片宽度 400px，居中
- 白色背景，圆角 12px，阴影
- 标题绿色，正文灰色
- 图片宽度 100%，圆角上方
- 底部联系方式有上边框分隔

**参考答案**：`exercises/css-01-card-style.html`

### 练习 5：Flex 导航栏

用 Flex 布局写一个导航栏：
- 左侧 Logo，右侧菜单项（首页/门店/关于）
- 高度 60px，背景绿色
- 菜单项水平排列，鼠标悬停变色
- 整体内容最大宽度 1200px 居中

**参考答案**：`exercises/css-02-flex-navbar.html`

### 练习 6：响应式网格

写一个响应式门店卡片网格：

- 平板（481px~768px）：2 列

- 卡片之间有间距，卡片有圆角和阴影

**参考答案**：`exercises/css-03-responsive-grid.html`

## JavaScript 练习（4 题）

### 练习 7：数组操作

给定门店数据数组，完成以下操作：
```javascript
const stores = [
  { id: 1, name: '门店A', sales: 12000, city: '北京', status: '营业中' },
  { id: 2, name: '门店B', sales: 8000, city: '上海', status: '休息中' },
  { id: 3, name: '门店C', sales: 15000, city: '北京', status: '营业中' },
  { id: 4, name: '门店D', sales: 5000, city: '广州', status: '营业中' },
  { id: 5, name: '门店E', sales: 20000, city: '上海', status: '休息中' }
];
```

任务：
1. 用 filter 找出所有"营业中"的门店
2. 用 map 提取所有门店的名称数组
3. 用 find 找出销售额最高的门店
4. 用 reduce 计算总销售额
5. 用 sort 按销售额降序排序
6. 用 filter + map 找出北京所有营业中的门店名称

**参考答案**：`exercises/js-01-array.html`（打开浏览器，按 F12 看控制台输出）

### 练习 8：对象与解构

```javascript
const projectDetail = {
  projectId: 1001,
  projectName: '小象超市·朝阳店',
  address: {
    city: '北京',
    district: '朝阳区',
    street: '建国路88号'
  },
  contact: {
    name: '张三',
    phone: '13800138000'
  },
  monthlySales: [12000, 15000, 13000, 16000]
};
```

任务：
1. 用解构提取 projectId 和 projectName
2. 用嵌套解构提取 address 中的 city 和 district
3. 用解构提取 contact 中的 name，重命名为 contactName
4. 计算月均销售额（reduce）
5. 用展开运算符复制 projectDetail 并添加 email 字段

**参考答案**：`exercises/js-02-object.html`

### 练习 9：异步请求模拟

模拟一个"加载门店详情"的异步流程：
1. 写一个 mockRequest 函数，返回 Promise，1 秒后 resolve 数据
2. 用 async/await 调用，先显示"加载中..."
3. 加载完成后显示门店信息
4. 用 Promise.all 同时加载"门店详情"和"门店订单"
5. 处理可能的错误

**参考答案**：`exercises/js-03-async.html`

### 练习 10：综合小应用

用 HTML + CSS + JS 写一个"门店搜索器"：
- 一个输入框输入城市名
- 一个搜索按钮
- 点击搜索后，从给定的门店数组中筛选对应城市的门店
- 结果以卡片列表形式展示
- 没有结果时显示"未找到门店"

**参考答案**：`exercises/js-04-search-app.html`
