第1章：HTML 基础结构

<!DOCTYPE html> 文档类型声明

告诉浏览器以标准模式渲染页面。HTML5 的写法非常简洁，只需要 <!DOCTYPE html>。如果不写，浏览器可能进入"怪异模式"，导致页面样式表现不一致。

<!-- HTML5 的 DOCTYPE 声明，必须是 HTML 文档的第一行 --> <!DOCTYPE html>

<html> 根标签

所有 HTML 内容的根容器。lang 属性声明页面语言，有利于 SEO 和无障碍访问。

属性说明
lang声明页面语言，如 zh-CN（简体中文）、en（英文）
manifestHTML5 离线应用缓存清单文件路径（已废弃）
<html lang="zh-CN"> <!-- head 和 body 都在这里面 --> </html>

<head> 头部区域

head 区域的元素不会在页面上直接显示内容，主要用于设置网页的元信息、引入外部资源（CSS、JS）。包含：meta、title、style、link、script、base 等标签。

<body> 主体区域

body 区域的元素会直接显示在页面上。所有用户可见的内容（文字、图片、表格、表单等）都放在这里。

<body> <!-- 所有可见内容放在这里 --> <h1> Hello World </h1> </body>

完整 HTML 文档结构

<!DOCTYPE html> <html lang="zh-CN"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>网页标题</title> </head> <body> <!-- 网页内容 --> </body> </html>

第2章：排版标签

排版标签是 HTML 中最基础的内容组织标签，用于控制文字的排列和段落结构。

<h1> ~ <h6> 标题标签

HTML 提供了 6 级标题，h1 最大最重要，h6 最小。标题标签是块级元素，会独占一行。搜索引擎非常重视 h1 标签的内容。

💡 每个页面建议只有一个 <h1> 标签，用于页面的主标题，有利于 SEO。
<h1>一级标题（最大）</h1> <h2>二级标题</h2> <h3>三级标题</h3> <h4>四级标题</h4> <h5>五级标题</h5> <h6>六级标题（最小）</h6>
渲染效果：

一级标题（最大）

二级标题

三级标题

四级标题

五级标题
六级标题（最小）

<p> 段落标签

表示一个段落，是块级元素。浏览器会自动在段落前后添加一些间距。p 标签中不能嵌套块级元素（如 div）。

<p>这是一个段落。段落之间会有自动间距。</p> <p>这是另一个段落。</p>
渲染效果：

这是一个段落。段落之间会有自动间距。

这是另一个段落。

<hr> 水平线标签（单标签）

在页面中插入一条水平分割线，用于分隔内容。是自闭合标签，不需要写结束标签。

属性说明
size水平线粗细（像素）—— HTML5 已废弃，建议用 CSS
width水平线宽度 —— HTML5 已废弃，建议用 CSS
color水平线颜色 —— HTML5 已废弃，建议用 CSS
align对齐方式 —— HTML5 已废弃，建议用 CSS
<p>上面的内容</p> <hr> <!-- 单标签，不需要闭合 --> <p>下面的内容</p>
渲染效果：

上面的内容

下面的内容

<br> 换行标签（单标签）

强制换行，是自闭合标签。与 p 标签不同，br 不会产生段落间距，只是简单换行。

⚠️ 不要用连续的 <br> 来制造间距，应该用 CSS 的 margin/padding。
第一行<br>第二行<br>第三行
渲染效果：
第一行
第二行
第三行

<div> 容器标签（块级元素）

div 是最常见的块级容器标签，本身没有语义，主要用于分组和布局。会独占一行，可以设置宽高。

💡 div 是最通用的元素，大多数场景都可以用。但也正因为如此，它的语义不明确。HTML5 新增了语义化标签（header、nav、section 等）来替代部分 div 的用途。
<div class="header"> <h1>网站标题</h1> </div> <div class="main"> <p>主要内容</p> </div>

<span> 行内容器标签（行内元素）

span 是行内元素，不会独占一行。本身没有语义，用于对一小段文字应用样式或进行逻辑分组。

<p>这是一段文字，其中<span style="color:red">这几个字是红色</span>的。</p>
渲染效果：

这是一段文字，其中这几个字是红色的。

<center> 居中标签（已废弃）

将其中的内容居中显示。HTML5 中已废弃，建议使用 CSS 的 text-align: center 或 margin: 0 auto 来实现。

<!-- 已废弃，不推荐使用 --> <center>这段文字居中</center> <!-- 推荐用 CSS 替代 --> <div style="text-align: center">这段文字居中</div>

<pre> 预格式化标签

保留文本中的空格和换行符，通常用于展示代码。浏览器默认用等宽字体显示 pre 标签内的内容。

<pre> function hello() { console.log("Hello!"); return true; } </pre>
渲染效果：
function hello() {
    console.log("Hello!");
    return true;
}

<blockquote> 块引用标签

表示一段引用的内容，浏览器会默认添加缩进。常用于引用他人的文章或话语。

属性说明
cite引用来源的 URL
<blockquote cite="https://example.com"> 这是一段引用的文字。 </blockquote>
渲染效果：
这是一段引用的文字。

第3章：HTML 注释

HTML 注释语法

注释不会在页面上显示，但可以在"查看源代码"时看到。良好的注释习惯有助于团队协作和代码维护。

<!-- 这是单行注释 --> <!-- 这是多行注释 可以写很多行 浏览器不会显示注释内容 --> <!-- 条件注释：只有 IE 浏览器能识别 用于解决 IE 兼容性问题 --> <!--[if lte ie 8]> <script src="html5shiv.min.js"></script> <![endif]-->
💡 条件注释中：lte = less than or equal（小于等于），gte = greater than or equal（大于等于）

第4章：字体标签与超链接

HTML 特殊字符

HTML 中有些字符是保留的（如 < > &），如果需要显示这些字符本身，就要用实体字符。

特殊字符实体写法说明
空格&nbsp;一个不间断空格（HTML 中连续空格只显示一个）
<&lt;小于号
>&gt;大于号
&&amp;与号
©&copy;版权符号
®&reg;注册商标符号
™&trade;商标符号
×&times;乘号 ×
÷&divide;除号 ÷
<!-- 显示多个空格 --> 字&nbsp;&nbsp;&nbsp;间距 <!-- 显示 HTML 标签本身 --> &lt;div&gt; 这是一个 div 标签 <!-- 版权信息 --> Copyright &copy; 2024

<font> 字体标签（已废弃）

用于设置文字的字体、大小和颜色。HTML5 中已废弃，建议使用 CSS 替代。

属性说明
face字体名称 —— 已废弃，用 CSS font-family
size字体大小（1-7）—— 已废弃，用 CSS font-size
color字体颜色 —— 已废弃，用 CSS color
<!-- 已废弃，不推荐 --> <font color="red" size="5" face="微软雅黑">红色5号字</font> <!-- 推荐用 CSS --> <span style="color:red; font-size:20px; font-family:'微软雅黑'">红色20px字</span>

<b> 和 <strong> 粗体标签

b 标签将文字加粗显示，但没有语义。strong 标签也有加粗效果，且具有"强调"的语义，搜索引擎会更重视 strong 中的内容。

💡 推荐使用 <strong> 而不是 <b>，因为 strong 有语义（表示重要内容）。
<b>粗体文字（无语义）</b> <strong>重要内容（有语义强调）</strong>
渲染效果：
粗体文字（无语义） ｜ 重要内容（有语义强调）

<u> 下划线标签

给文字添加下划线。HTML5 中不推荐使用，建议用 CSS 的 text-decoration: underline。

<u>这段文字有下划线</u> <!-- CSS 替代方案 --> <span style="text-decoration: underline">这段文字有下划线</span>
渲染效果：
这段文字有下划线

<i> 和 <em> 斜体标签

i 标签将文字显示为斜体，但没有语义（纯样式）。em 标签也有斜体效果，且具有"强调"的语义。HTML5 中推荐用 em 替代 i。

<i>斜体文字（纯样式）</i> <em>强调文字（有语义）</em>
渲染效果：
斜体文字（纯样式） ｜ 强调文字（有语义）

<s> 和 <del> 删除线标签

s 标签添加删除线（纯样式）。del 标签也表示删除线，且有语义（表示被删除的内容），常用于显示价格变动。

<s>原价：￥99</s> <del>原价：￥99</del> 现价：￥59
渲染效果：
原价：￥99 → 原价：￥99 现价：￥59

<sup> 和 <sub> 上标和下标

sup 标签将文字变为上标（如数学指数）。sub 标签将文字变为下标（如化学公式）。

<!-- 上标：数学指数 --> 2<sup>10</sup> = 1024 <!-- 下标：化学公式 --> H<sub>2</sub>O = 水 CO<sub>2</sub> = 二氧化碳
渲染效果：
210 = 1024
H2O = 水
CO2 = 二氧化碳

<a> 超链接标签

a 标签是 HTML 中最重要的标签之一，用于创建超链接，实现页面跳转、锚点定位、邮件发送等功能。

属性说明
href链接目标地址（URL）。可以是绝对路径、相对路径或锚点
target链接打开方式：_blank（新窗口）、_self（当前窗口，默认）、_parent（父窗口）、_top（顶层窗口）
title鼠标悬停时显示的提示文字
name设置锚点名称（HTML5 中推荐用 id 替代）
downloadHTML5 新增，指定下载文件名

1. 外部链接

<!-- 在新窗口打开外部网站 --> <a href="https://www.baidu.com" target="_blank" title="百度搜索">百度</a>
渲染效果：
百度

2. 内部链接（相对路径）

<!-- 相对路径：同级目录 --> <a href="index.html">首页</a> <!-- 相对路径：上级目录 --> <a href="../about.html">关于我们</a> <!-- 相对路径：子目录 --> <a href="pages/contact.html">联系我们</a>

3. 锚点链接（页面内跳转）

<!-- 定义锚点（HTML5 推荐用 id） --> <h2 id="chapter1">第一章</h2> <!-- 跳转到锚点 --> <a href="#chapter1">跳转到第一章</a> <!-- 跳回页面顶部 --> <a href="#">回到顶部</a>
渲染效果：
跳转到第一章：HTML 基础结构 ｜ 回到顶部

4. 邮件链接

<!-- 点击后打开邮件客户端 --> <a href="mailto:someone@example.com">给我发邮件</a> <!-- 带抄送和主题 --> <a href="mailto:someone@example.com?cc=other@example.com&subject=你好">给我发邮件</a>

5. 下载链接（HTML5）

<!-- download 属性指定下载文件名 --> <a href="files/report.pdf" download="年度报告.pdf">下载报告</a>
💡 HTML5 中，a 标签可以包裹块级元素（如 div），这是合法的。但在 HTML 4.01 中不合法。

第5章：图片标签

<img> 图片标签（单标签）

img 标签用于在网页中插入图片，是自闭合标签。它是行内块元素（inline-block）。

属性说明
src图片路径（必需）。可以是相对路径、绝对路径或网络URL
alt图片无法显示时的替代文字（必需）。对 SEO 和无障碍访问很重要
width图片宽度（像素）。建议用 CSS 控制
height图片高度（像素）。建议用 CSS 控制
title鼠标悬停时显示的提示文字
<!-- 同级目录 --> <img src="logo.png" alt="网站Logo"> <!-- 上一级目录 --> <img src="../images/bg.jpg" alt="背景图"> <!-- 网络URL --> <img src="https://www.example.com/images/banner.jpg" alt="横幅" width="800" height="200" title="点击查看大图">
⚠️ alt 属性必须写！图片加载失败时显示 alt 文字。搜索引擎靠 alt 理解图片内容。
💡 只设 width 或 height 中的一个，图片会自动按比例缩放。同时设两个可能导致变形。

支持的图片格式

格式特点适用场景
JPG/JPEG有损压缩，文件小，不支持透明照片、色彩丰富的图片
PNG无损压缩，支持透明图标、Logo、需要透明背景的图片
GIF支持动画，只有256色简单动画、表情包
WebPGoogle推出，体积更小，支持透明和动画现代网页图片
SVG矢量图形，无限缩放不失真图标、图表、Logo

第6章：列表标签

<ul> 无序列表

ul（Unordered List）表示无序列表，列表项前面显示项目符号（默认实心圆点）。

<ul> <li>苹果</li> <li>香蕉</li> <li>橘子</li> </ul>
渲染效果：
  • 苹果
  • 香蕉
  • 橘子
💡 常用 ul + li 做导航菜单、商品列表。用 CSS list-style: none 去掉项目符号。

<ol> 有序列表

ol（Ordered List）表示有序列表，列表项前面显示序号。

属性说明
type序号类型：1（数字）、a（小写字母）、A（大写字母）、i（小写罗马）、I（大写罗马）
start序号起始值
reversedHTML5 新增，倒序排列
<ol type="1" start="1"> <li>第一步：打开浏览器</li> <li>第二步：输入网址</li> <li>第三步：按下回车</li> </ol>
渲染效果：
  1. 第一步：打开浏览器
  2. 第二步：输入网址
  3. 第三步：按下回车

<dl> 定义列表

dl 用于定义术语和描述的对应关系。dt 是术语，dd 是描述。常用于 FAQ、词典。

<dl> <dt>HTML</dt> <dd>超文本标记语言，用于构建网页结构</dd> <dt>CSS</dt> <dd>层叠样式表，用于设置网页样式</dd> </dl>
渲染效果：
HTML
超文本标记语言，用于构建网页结构
CSS
层叠样式表，用于设置网页样式

<li> 列表项

li 必须放在 ul 或 ol 中。li 中可以嵌套其他标签（包括另一个列表）。

属性说明
value设置当前列表项的序号（仅 ol 中有效）

嵌套列表示例

<ul> <li>前端 <ul> <li>HTML</li> <li>CSS</li> <li>JavaScript</li> </ul> </li> <li>后端 <ul> <li>Java</li> <li>Python</li> </ul> </li> </ul>
渲染效果：
  • 前端
    • HTML
    • CSS
    • JavaScript
  • 后端
    • Java
    • Python

第7章：表格标签

表格用于展示结构化数据。一个完整表格包含：table > caption > thead > tbody > tfoot > tr > th/td。

<table> 表格根容器

属性说明
border边框粗细 —— 已废弃，用 CSS border
cellpadding单元格内边距 —— 已废弃，用 CSS padding
cellspacing单元格间距 —— 已废弃，用 CSS border-spacing

<caption> 表格标题

表格的标题，必须放在 table 的第一个子元素位置。

<thead> / <tbody> / <tfoot> 表格结构分组

thead 表头，tbody 主体，tfoot 表尾。让表格结构更清晰。即使不写 tbody，浏览器也会自动添加。

<tr> 表格行 / <th> 表头单元格 / <td> 普通单元格

属性说明
colspan横向合并（跨列）。值为合并的列数
rowspan纵向合并（跨行）。值为合并的行数

完整表格示例

<table border="1" style="border-collapse: collapse; width: 100%;"> <caption>员工信息表</caption> <thead> <tr> <th>姓名</th> <th>年龄</th> <th>部门</th> </tr> </thead> <tbody> <tr><td>张三</td><td>25</td><td>技术部</td></tr> <tr><td>李四</td><td>30</td><td>市场部</td></tr> </tbody> <tfoot> <tr><td colspan="3">合计：2人</td></tr> </tfoot> </table>
渲染效果：
员工信息表
姓名年龄部门
张三25技术部
李四30市场部
合计：2人

单元格合并示例

<table border="1" style="border-collapse: collapse;"> <tr> <!-- colspan="2" 横向合并两列 --> <th colspan="2">个人信息</th> <!-- rowspan="2" 纵向合并两行 --> <th rowspan="2">备注</th> </tr> <tr> <th>姓名</th> <th>年龄</th> </tr> <tr> <td>王五</td> <td>28</td> <td>优秀员工</td> </tr> </table>
渲染效果：
个人信息备注
姓名年龄
王五28优秀员工
💡 colspan 横向合并（合并几列），rowspan 纵向合并（合并几行）。合并后要少写对应的 td/th。

第8章：表单标签

表单是 HTML 中用于收集用户输入的标签集合，是网页交互的核心。

<form> 表单标签

属性说明
action表单数据提交的目标 URL
method提交方式：GET（默认）或 POST
enctype编码类型：application/x-www-form-urlencoded（默认）、multipart/form-data（文件上传）、text/plain
novalidateHTML5 新增，禁用浏览器自动验证
💡 GET 适合少量非敏感数据（显示在URL中），POST 适合大量或敏感数据。文件上传必须用 POST + enctype="multipart/form-data"。

<input> 输入框标签（单标签）

input 通过 type 属性变成不同类型的输入控件。

属性说明
type输入类型（见下表）
name控件名称，提交数据时的键名（必需）
value控件的默认值
placeholderHTML5，输入框提示文字
requiredHTML5，是否必填
disabled禁用控件（不可编辑，不提交数据）
readonly只读（不可编辑，但会提交数据）
maxlength最大输入字符数
patternHTML5，正则验证模式
autofocusHTML5，自动获取焦点
autocompleteHTML5，自动完成（on/off）
multipleHTML5，允许多选（file、email）

type 类型详解

type 值说明
text文本输入框（默认）
password密码框，输入内容显示为圆点
radio单选按钮，同 name 只能选一个
checkbox复选框，可以多选
submit提交按钮
reset重置按钮
button普通按钮（需配合JS）
file文件上传
hidden隐藏域（不可见，用于提交额外数据）
image图片提交按钮（用 src 指定图片）
<!-- 文本框 --> <input type="text" name="username" placeholder="请输入用户名" required> <!-- 密码框 --> <input type="password" name="pwd" placeholder="请输入密码"> <!-- 单选按钮 --> <input type="radio" name="gender" value="male" checked>男 <input type="radio" name="gender" value="female">女 <!-- 复选框 --> <input type="checkbox" name="hobby" value="reading" checked>阅读 <input type="checkbox" name="hobby" value="coding">编程 <!-- 文件上传 --> <input type="file" name="avatar" accept="image/*" multiple> <!-- 隐藏域 --> <input type="hidden" name="id" value="123">
渲染效果：

用户名：

密码：

性别：男 女

爱好：阅读 编程

第16章：HTML5 多媒体播放器

通过 video 标签配合 JavaScript，可以自定义一个简单的视频播放器。

2. 视频加载完成后计算总时长并显示

3. 播放时进度条同步、当前时间同步

4. 点击全屏按钮实现全屏播放

播放器代码示例

// 添加一个历史记录（URL变化但不刷新页面） history.pushState({page: 1}, '标题', '?page=1'); // 监听历史记录变化（前进/后退时触发） window.addEventListener('popstate', function(e) { console.log(e.state); // 获取状态数据 });
💡 pushState 是前端路由（Vue Router、React Router）的底层基础。

第23章：HTML 元素分类与嵌套规则

按样式分类

类型特点常见标签
块级元素（block）独占一行，可以设置宽高div、p、h1-h6、ul、ol、table、form
行内元素（inline）不独占一行，不能设置宽高span、a、em、strong、b、i
行内块元素（inline-block）不独占一行，可以设置宽高img、input、button、select、textarea

嵌套规则

1. 块级元素可以包含行内元素。

2. 块级元素不一定能包含块级元素。如 div 中可以包含 div，但 p 标签中不能包含 div。

3. 行内元素一般不能包含块级元素。如 span 中不能包含 div。

4. 特例：在 HTML5 中，a 标签可以包含 div（a > div 合法），但 div > a > div 不合法。

💡 嵌套规则的本质是内容模型（Content Model）的约束，详见 HTML 规范。

第24章：CSS Reset 与 Normalize

浏览器对 HTML 元素提供了默认样式，但不同浏览器的默认样式可能不一致。需要统一处理。

为什么需要 CSS Reset？

有些默认样式我们不需要（如 body 的 margin），有些默认样式在不同浏览器中不一致（如 h1 的字体大小）。如果不清零，会导致页面在不同浏览器中表现不同。

方案一：Reset CSS（清零方案）

思路：将所有默认样式全部清零。代表：Eric Meyer 的 Reset CSS、Yahoo Reset CSS。

/* 最简单的 Reset（有争议） */ * { margin: 0; padding: 0; } /* Eric Meyer 的 Reset CSS（更完整） */ /* 参考链接：https://meyerweb.com/eric/tools/css/reset/ */
⚠️ *{margin:0;padding:0} 虽然简洁，但可能导致 CSS 选择器性能问题（匹配所有元素）。

方案二：Normalize.css（统一方案）

思路：不删除默认样式，而是将不同浏览器的默认样式统一为一致的标准。保留了有用的默认样式。

<!-- 通过 CDN 引入 --> <link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/normalize.css@8.0.1/normalize.css">
💡 Normalize.css 是目前最流行的方案，很多前端框架（如 Bootstrap）都基于它。

第25章：HTML 常见面试题

Q1：doctype 的意义是什么？

1. 让浏览器以标准模式渲染页面（避免怪异模式）。

2. 让浏览器知道元素的合法性（遵循哪个 HTML 版本规范）。

Q2：HTML、XHTML、HTML5 的区别？

HTML 属于 SGML（标准通用标记语言）。

XHTML 属于 XML，是 HTML 进行 XML 严格化的结果（标签必须闭合、属性必须引号包裹等）。

HTML5 不属于 SGML 也不属于 XML，有自己独立的规范，比 XHTML 更宽松。

Q3：HTML5 有什么新的变化？

1. 新的语义化元素（header、nav、section、article、aside、footer）。

2. 表单增强（新 type 类型、新属性、datalist 等）。

3. 新的 API：离线（应用缓存）、音视频（audio/video）、图形（canvas）、实时通信（WebSocket）、本地存储（localStorage/sessionStorage）、设备能力（地理定位、拖拽、全屏）等。

Q4：em 和 i 的区别？

共同点：两者都显示斜体效果。

区别：em 是语义化标签，表示强调。i 是纯样式标签，表示斜体，HTML5 中不推荐使用。

Q5：语义化的意义是什么？

1. 开发者容易理解代码结构，便于维护。

2. 机器（搜索引擎、读屏软件）容易理解页面结构。

3. 有助于 SEO（搜索引擎优化）。

Q6：哪些元素可以自闭合？

自闭合元素中不能再嵌入别的元素。

表单元素：input。图片：img。排版：br、hr。头部：meta、link。媒体：source、track。其他：area、col、embed、param、wbr。

Q7：form 表单的作用？

1. 直接提交表单数据到服务器。

2. 使用 submit/reset 按钮。

3. 便于浏览器保存表单（自动填充）。

4. 第三方库可以整体获取值。

5. 第三方库可以进行表单验证。

所以即使通过 Ajax 提交表单数据，也建议加上 form 标签。

Q9：HTML5 的 data-* 自定义属性

HTML5 允许在标签上添加以 data- 开头的自定义属性，通过 dataset API 访问。

<!-- HTML --> <div class="box" data-my-name="张三" data-age="25">内容</div> <script> var box = document.querySelector('.box'); // 通过 dataset 获取（连字符转为驼峰） console.log(box.dataset.myName); // 张三 console.log(box.dataset.age); // 25 // 设置值 box.dataset.age = '26'; </script>
